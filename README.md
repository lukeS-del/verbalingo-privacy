# verbalingo-privacy

Публичные документы приложения **Verbalingo** — тренажёра английского для
русскоязычных.

Опубликовано: <https://lukes-del.github.io/verbalingo-privacy/>

Этот репозиторий существует отдельно от кода приложения, который остаётся
закрытым. Здесь только то, на что Google Play обязан иметь публичную ссылку, и
то, что должно оставаться доступным без входа в аккаунт всё время, пока
приложение есть в магазине.

- `index.html` — политика конфиденциальности, на русском и английском.
  Канонический текст: копии в других местах не хранятся, чтобы не разошлись.
- `delete-account.html` — как удалить аккаунт. Play требует, чтобы такой путь
  существовал и вне приложения: страница должна открываться у человека, который
  приложение уже удалил, и её адрес указывается в Play Console отдельным полем.
  Ссылка на неё есть в политике, в обоих языковых блоках.

Правки — прямо в `index.html`. GitHub Pages публикует ветку `main` как есть,
без сборки: что закоммичено, то и открывается через минуту. Меняя смысл
документа, а не опечатку, поменяйте и дату вступления в силу — в обоих
языковых блоках.
